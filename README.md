# 寂辉知识库采访

用 19 个结构化问题，把散落在脑子里的业务判断整理成六类可持续维护的知识：个人与品牌、产品与服务、客户与场景、方法与流程、案例与证据、内容与表达。

## 安装

```bash
npx skills add Amentman/jihui-interview@jihui-interview -g -y
```

安装后可以说：`使用 $jihui-interview 开始采访，并帮我搭建业务知识库。`

## 它会做什么

- 先读取已有目录，已有知识库就沿用原结构。
- 一次只问一个问题，保留原话、数字和不确定项。
- 采访后输出总览、六库文件、待确认事项和后续行动。
- 不会虚构案例、成绩或客户评价。

示例见 [合成采访示例](skills/jihui-interview/references/synthetic-example.md)。许可证：MIT。
