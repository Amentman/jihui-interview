# 合成采访示例

以下人物和内容均为虚构，仅展示输出方式。

- 用户：林舟，自由职业设计顾问。
- 原话：“客户不是缺一张好看的图，而是不知道为什么现在必须改。”
- 可归入：客户与场景库、方法与流程库、内容与表达库。
- 待确认：是否有可公开的改版前后数据。
- 下一步：补充一个经过授权的匿名项目，记录背景、动作、结果和证据。

    00-总览/知识地图.md
